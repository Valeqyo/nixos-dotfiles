## 🧾 Overview

This is **Valeqyo**'s full NixOS configuration: system, hardware, home-manager and application dotfiles, all managed by a single flake and rebuildable with one command.

Key points:

- **Modular** setup: `modules/` for system configuration (NixOS), `home-modules/` for the user (Home Manager).
- Application dotfiles in `config/` are **not** copied into the Nix store, they're linked out-of-store (`mkOutOfStoreSymlink`) so they can be edited live without a rebuild.
- **Hyprland** as compositor, configured with the newer **Lua** syntax (`hl.*`) instead of the classic `hyprland.conf`.
- **Limine** bootloader with a Plymouth splash and custom wallpaper, plus extra entries for dual-booting with Windows/openSUSE.
- Consistent **Rosé Pine** look across terminal, prompt, waybar, rofi, lockscreen, notifications, GTK, cursors and icons.
- Fish aliases/functions for one-command rebuild/update (`up`, `update`).

## 🖥️ Target hardware

This configuration is built for a specific machine:

- **Intel** CPU (microcode auto-updated)
- **NVIDIA** GPU (proprietary driver `legacy_580`, modesetting enabled)
- **UEFI** boot, **ext4** root filesystem, **vfat** boot partition
- Extra disks mounted at `/mnt/linuxhdd` (ext4) and `/mnt/zame` (exFAT)
- Dual-boot with **Windows** and (temporarily) **openSUSE**, both added as extra entries in the Limine bootloader

> If you clone this repo onto different hardware, regenerate `hardware-configuration.nix` with `nixos-generate-config` and adjust `modules/hardware/*.nix` (disk UUIDs, GPU, hostname).

## 🚀 Installation

```bash
# 1. Clone the repository into your home directory
git clone https://github.com/Valeqyo/nixos-dotfiles.git ~/nixos-dotfiles
cd ~/nixos-dotfiles

# 2. (on different hardware) regenerate the hardware config
sudo nixos-generate-config --show-hardware-config > hardware-configuration.nix

# 3. Apply the configuration
sudo nixos-rebuild switch --flake .#nixos-btw
```

The system hostname is `nixos-btw` (set in `flake.nix` and `modules/hardware/networking.nix`), the main user is `comar`.

## 🛠️ Useful commands

Defined in `config/fish/config.fish`:

| Command | What it does |
|---|---|
| `up` | `git add .` → `nixos-rebuild switch --flake ~/nixos-dotfiles#nixos-btw` → refreshes the fastfetch cache |
| `update` | Alias for `scripts/update`: updates `flake.lock`, rebuilds, and if there are changes, auto commits + pushes |
| `config` | `cd ~/nixos-dotfiles/config` |
| `clear` | `clear` + `fastfetch` |

## 🪟 Hyprland

Hyprland is **not** configured with the classic `hyprland.conf`, but with the newer **Lua**-based syntax (`hl.*`), split into modules loaded from `hyprland.lua`:

- `monitors.lua` — external monitor `HDMI-A-1` at `1920x1080@59.94` scaled 1.20, workspaces 1-6 and 9 pinned to it
- `binds.lua` — keyboard, mouse and media key bindings
- `autostart.lua` — starts waybar, swaync, awww (wallpaper daemon), cliphist, hypridle, nm-applet, ferdium
- `decoration.lua` — borders, shadows, blur, animations (custom curves/springs)
- `layouts.lua` — dwindle as the main layout
- `input.lua` — IT keyboard layout, 3-finger gesture to switch workspaces
- `windowrules.lua` — floating rules for utility popups (btop, pavucontrol, satty...), automatic app→workspace assignment (Firefox→1, VSCode→3, ONLYOFFICE→4, Ferdium→5, Steam/Heroic→6, Spotify→9), Firefox PiP pinned to the bottom-right

`hyprlock.conf` shows the time, date, profile picture, **currently playing song** (via `playerctl`, `playing.sh` script) and **weather** (via `wttr.in`, `weather.sh` script).

`SUPER` is the main modifier.

| Combination | Action |
|---|---|

| `SUPER + B` | Browser (Firefox) |
| `SUPER + SPACE` | App launcher (Rofi) |
| `SUPER + V` | Clipboard history (cliphist + Rofi) |
| `SUPER + N` | Notification center (SwayNC) |
| `SUPER + SHIFT + N` | Power menu |
| `SUPER + S` | Screenshot/recording menu |
| `SUPER + SHIFT + S` | Screenshot of selected area → Satty |
| `SUPER + T` | Toggle floating window |
| `SUPER + F` | Toggle fullscreen (internal) |
| `SUPER + SHIFT + F` | Toggle fullscreen (real) |
| `SUPER + J` | Toggle dwindle split |
| `SUPER + [arrows]` | Move focus |
| `SUPER + [0-9]` | Go to workspace |

| Media keys | Volume, brightness, play/pause via `playerctl`/`volumectl`/`lightctl` |

## 📊 Waybar

A minimal top bar: Hyprland workspaces on the left, clock in the center, system tray, Caps Lock indicator, volume control (with slider), CPU/RAM/disk/battery and the notification center on the right. Clicking CPU/RAM opens `btop` in a floating Kitty window.

## 🔍 Rofi

Four independent Rofi setups, all Rosé Pine themed:

- **`type-3/`** — main app launcher (`drun`), `style-9`
- **`clipboard/`** — clipboard history with image previews (cliphist), `style-2`
- **`powermenu/type-2/`** — power menu with confirmation (lock/suspend/logout/reboot/shutdown), `style-4`
- **`screenshot/`** — screenshot/recording menu (full screen, area, video)

Themes based on the style packs by [adi1090x](https://github.com/adi1090x/rofi).

## 🔔 Notifications — SwayNC

Notification center top-right with an mpris widget, DND, and a quick-action button grid using custom scripts:

- `caffeine` — inhibits suspend (systemd-inhibit)
- `mictoggle` — mute/unmute microphone with a notification
- `powerprofile` — cycles power profiles (asusctl or powerprofilesctl)
- `nwg-look` — opens the GTK theming tool

## 💻 Terminal, shell and prompt

- **Kitty** with `JetBrainsMono Nerd Font Mono`, Rosé Pine theme imported from `current-theme.conf`
- **Fish** as the default shell, `fastfetch` on open, prompt handled by **Starship** with segments for directory, git branch/status, time and detected programming languages — all in the Rosé Pine palette

## 🎨 Theme consistency

The [Rosé Pine](https://rosepinetheme.com/) theme is applied consistently across:

Hyprland (borders/decorations) · Hyprlock · Kitty · Starship · Waybar · Rofi (all setups) · SwayNC · GTK (`rose-pine-gtk-theme`) · cursors (`rose-pine-cursor` / `rose-pine-hyprcursor`) · icons (`rose-pine-icon-theme`) · VS Code (`mvllow.rose-pine` extension)

The wallpaper (`assets/Lowpoly_Street.png`) is shared between the Limine bootloader, Hyprlock and the desktop (set via `awww`).

## 📝 Notes

- Comments across the config files are a mix of English and Italian — you'll run into both depending on the file.
- The *openSUSE* boot entry in `modules/boot.nix` is marked by the author as temporary, to be removed once that partition is gone.
- `scripts/update` auto-pushes to `main`: fine for personal use, use with caution if the repo is shared or forked.
